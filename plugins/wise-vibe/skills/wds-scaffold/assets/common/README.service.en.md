## Run model

Everything runs through **docker compose**, in two modes: **local** and **prod**.

| Mode | compose files | env file | DB | image stage |
|------|---------------|----------|----|-------------|
| local | `docker-compose.yml` + `docker-compose.local.yml` | `.env.local` (committed) | SQLite (`/app/data/app.db`) | `dev` (bind mount, hot reload) |
| prod | `docker-compose.yml` + `docker-compose.prod.yml` | `.env.prod` (never committed) | `{{DB_ENGINE}}` | `runtime` |

Optional infrastructure in `compose/*.yml` (redis, kafka, …) is included in both modes.

## Requirements

Docker Engine or Docker Desktop with Compose v2, and GNU Make. No language toolchain is needed on the host.

## Quick start

```bash
make preflight
make local-all
curl http://127.0.0.1:{{APP_PORT}}/health
make test
make local-stop
```

prod mode (local rehearsal or the target host):

```bash
cp .env.example .env.prod   # only if missing — replace CHANGE_ME with secrets from your secret manager
make prod-all
make db-ping ENV=prod
make db-migrate ENV=prod
```

## Make targets

| Target | Description |
|--------|-------------|
| `make <mode>-all` | Start the stack (`mode` = local \| prod) |
| `make <mode>-build` | Rebuild images and start |
| `make <mode>-logs [SVC=]` | Follow logs |
| `make <mode>-stop` | Remove containers (volumes kept) |
| `make <mode>-restart [SVC=]` | Restart |
| `make <mode>-ps` | Status |
| `make test` | Run tests in the local dev container |
| `make shell [ENV=]` | Shell into the app container |
| `make db-ping [ENV=]` | Check DB connectivity |
| `make db-shell ENV=prod` | RDBMS client |
| `make db-migrate / db-seed [ENV=]` | Migrate / seed |
| `make db-reset / db-fresh` | Reset local SQLite (+ seed); refused for prod |
| `make deploy` | Roll out prod (refused while CHANGE_ME remains) |
| `make preflight / help` | Checks / target list |

## Environment

| Variable | local | prod |
|----------|-------|------|
| `APP_ENV` | `local` | `prod` |
| `DB_ENGINE` | `sqlite` | `{{DB_ENGINE}}` |
| `DATABASE_URL` | SQLite file | connection string to the `db` service |
| `DB_USER` / `DB_PASSWORD` / `DB_NAME` | — | RDBMS account (CHANGE_ME → injected) |

To switch the prod engine, re-run `wds-scaffold {{PROFILE_ID}} --db postgres|mysql|mariadb|sqlite --force`.
