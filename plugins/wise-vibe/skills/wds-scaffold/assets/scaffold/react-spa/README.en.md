There is no database. All data goes through the API (`/api`); no screen-only business logic.

## Run model

| Mode | compose files | env file | server | image stage |
|------|---------------|----------|--------|-------------|
| local | `docker-compose.yml` + `docker-compose.local.yml` | `.env.local` (committed) | Vite dev server (HMR) | `dev` (bind mount) |
| prod | `docker-compose.yml` + `docker-compose.prod.yml` | `.env.prod` (never committed) | non-root nginx, read-only FS | `runtime` |

`/api` is proxied to `API_UPSTREAM` (same origin: no CORS, tokens never leave the origin). Responses carry CSP, X-Frame-Options, nosniff and Referrer-Policy headers.
The API should serve `GET /api/v1/health` so the first page reports `ok`.

## Quick start

```bash
make preflight
make local-all
open http://127.0.0.1:{{APP_PORT}}
make test               # vitest + tsc
make local-stop
```

## Make targets

| Target | Description |
|--------|-------------|
| `make <mode>-all / -build / -logs / -stop / -restart / -ps` | lifecycle (`mode` = local \| prod) |
| `make test` | unit tests (Vitest) + type check |
| `make build-web` | production static build (`dist/`) |
| `make shell [ENV=]` | container shell |
| `make deploy` | prod rollout |
| `make preflight / help` | checks / list |

E2E uses Playwright (`e2e/`, `pnpm e2e`; install a browser with `pnpm exec playwright install firefox`).

## Tests

Single `test/` tree: `test/dev-env/`, `test/impl/<Nth>/`. Unit tests are `test/*.test.tsx`. Rules: `test/README.md`.
