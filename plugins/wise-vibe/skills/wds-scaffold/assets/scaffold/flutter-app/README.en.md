## Modes

Mobile apps do not run in containers. There are two modes, **local** and **prod**, mapped to build configurations (flavors).
If you need an API server, scaffold a server profile (for example `python-fastapi`) separately; it runs with docker compose in local/prod.

| Mode | Meaning | Signing |
|------|---------|---------|
| local | simulator/emulator + local API | debug |
| prod | store release build | release (injected from CI secrets/match — never committed) |

Configuration: `.env.local` / `.env.prod` → `--dart-define-from-file` → `lib/core/env.dart`
